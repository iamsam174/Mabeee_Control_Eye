# MaBeee Control Eyeアプリ（視線入力に対応したMaBeee制御アプリ）

## 概要
視線入力（Eye Tracking）やマウス操作などを利用して、乾電池型IoTデバイス「MaBeee（マビー）」をBluetooth経由で手軽にコントロールするWindows向けアプリケーションです。
Tobii Eye Tracker 5などを利用した視線入力やマウス操作で、単3形以上の乾電池を電源とするオモチャなどを簡単に動かすことができます。

## 特徴
- **MaBeee専用スキャン**: 起動後、PC周辺のMaBeeeだけを素早く見つけてペアリング可能です。Bluetooth特有の不要なデバイス（Unknown等）を排除したリストを表示します。
- **カメラ映像の表示**: アプリ背景にWebカメラの映像を表示しながら操作できます（視線入力アプリとの連携に最適）。
- **選べる3つの動作モード**:
  1. クリックまたは注視でタイマー実行（タイマー駆動）: ボタンを左クリック（または注視＝視線をとどめる）すると、設定された秒数だけオモチャなどが動きます。
  2. マウスオーバーでタイマー実行（ホバー駆動）: ボタンの上にマウスポインター（または視線）が入るとタイマーが開始されます。
  3. マウスポインターがボタン内にある間だけON*（ダイレクト駆動）: ボタンの上にマウスポインター（または視線）がある間だけオモチャなどが動き、はずすと即座に止まります。
- **カスタマイズ可能なUI**: ボタンのサイズ（特大〜小）、タイマー秒数（1〜180秒）、操作音の有無をご利用環境に合せて簡単に変更できます。

## 動作環境
- OS: Windows 10 / Windows 11
- Bluetooth 4.0以降対応のPC（MaBeeeとの通信に使用）
- Webカメラ（※「カメラ1」「カメラ2」などの映像を表示する場合のみ必要。不要な場合は「カメラなし」を選択可）

## 使用方法
1. 配布用のZIPファイルを解凍し、生成された `Mabeee_Control_Eye` フォルダを開きます。
2. フォルダ内にある **`Mabeee_Control_Eye.exe`** をダブルクリックして起動します。
   *(※同じフォルダ内にある `_internal` フォルダは、アプリの動作に必要なシステムファイル群です。削除したり、フォルダの外へ移動したり、名前を変更したりしないでください。)*
3. MaBeeeに単4電池をセットし、コントロールしたい対象の機器（おもちゃ等）に入れます。機器の電源をオンにしてください。
4. 画面左上の「🔍 MaBeeeを探査」ボタンをクリックします。
5. 「ペアリング」のドロップダウンから検出されたMaBeeeを選択し、「接続」ボタンを押します。
6. 接続が完了したら、タイマー秒数や動作モードを設定し、「マビーON」ボタンを操作してMaBeeeを動かします。

### キーボードショートカット
- `F11` : 全画面表示のオン／オフ切り替え
- `Esc` : 全画面表示の解除
- `1` / `2` / `3` : 動作モード①・②・③の素早い切り替え
- `←` / `→` : タイマー秒数の減算／加算（1秒ずつ）

### その他操作
- **ボタンの移動位置**: 画面中央の「マビーON」ボタンは、マウスでドラッグ＆ドロップすることで画面内の使いやすい位置に自由に動かすことができます。

## 更新履歴
### 260520版
- **高速起動化（onedir形式への変更）**: アプリアイコンをダブルクリックしてから画面が表示されるまでの時間を1〜2秒以内（ほぼ即座）に短縮しました。
- **二重起動防止機能**: アプリが既に起動している状態で再度実行した際、「アプリは既に起動しています」と警告メッセージを表示して多重起動を防ぐようにしました。
- **コンソールの非表示化**: アプリ起動時にコマンドプロンプトの黒い画面を表示しないように設定しました。

### 260516版
- **スキャン精度の向上**: デバイス名が取得できない場合でも、サービスUUIDによりMaBeeeを特定できるよう改善しました。
- **EXE化時の不具合修正**: PyInstallerでのビルド時にBluetooth通信が不安定になる問題を解消するため、UPX圧縮を無効化しました。
- **エラーハンドリングの強化**: 接続失敗時やスキャンエラー時に、原因を画面上に表示するようにしました。
- **パス設定の適正化**: EXE実行時に設定ファイル（config.ini）が実行ファイルと同じ場所に正しく保存されるよう修正しました。
